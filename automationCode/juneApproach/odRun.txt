How Validation Works
1. Lexer (text2PDF.l / lex.yy.c)
The lexer reads the input file character by character (not line by line).
It matches the longest possible string at each position using the regex rules in your .l file.
For each match, it returns a token (e.g., NUM, STRING, PDFDECLARATION, SPACE, etc.) to the parser.
2. Parser (generated.y / generated.tab.c)
The parser receives this stream of tokens from the lexer.
It tries to match the sequence of tokens against the grammar rules you defined in your .y file.
If the sequence of tokens matches the grammar, parsing succeeds; otherwise, you get a syntax error.
